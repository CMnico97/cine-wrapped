# Cine Wrapped

Plataforma web para la gestión de un cine y la consulta personalizada de estadísticas mediante la funcionalidad Cine Wrapped.

## Tecnologías

- React
- Node.js
- Express
- MySQL
- REST API
- JWT

## Estructura

- `frontend/`: aplicación web desarrollada con React.
- `backend/`: servidor y API REST desarrollados con Node.js y Express.
- `database/`: scripts relacionados con la base de datos.

## Funcionalidades principales

- Registro e inicio de sesión.
- Consulta de películas.
- Consulta de funciones.
- Selección de asientos.
- Compra simulada de entradas.
- Historial de entradas.
- Cine Wrapped.
- Administración de películas y funciones.
